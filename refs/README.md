# Reference library

Screenshots of real sites that set the quality bar for this one. They are other people's work, so this folder is ignored by git and never published with the site. Only this README is tracked.

| Folder | What goes in it |
|---|---|
| `heroes/` | First screens: headline, photo, call to action |
| `product-cards/` | Product grids and single product cards |
| `sections/` | Story, origin, certifications, process, contact |
| `nav-footer/` | Headers, menus, footers |
| `motion/` | Short screen recordings or frame sequences of transitions |

## Where to collect from

| Source | Good for |
|---|---|
| [Awwwards](https://www.awwwards.com) | Award-winning sites; the sites already listed in `mockups/RESEARCH.md` |
| [Savee](https://savee.com) | Mood boards: photography, type, colour, layout fragments |
| [Rebrand Gallery](https://www.rebrand.gallery) | Brand identity: logos, packaging, type systems, before and after |
| `inspo` MCP server | Whole pages of real production sites, searchable from a prompt |

## Naming

`<site>-<what>-<width>.png`, for example `flamingo-estate-hero-390.png`. Capture each reference at 390px and at 1440px.

## Using them

- Aim for 9 to 12 strong references per section type. Fewer strong ones beat many weak ones.
- Name the references in the prompt and say what to take from each (light, spacing, type scale, photo treatment).
- The critic pass compares a 390px screenshot of our section against these.
