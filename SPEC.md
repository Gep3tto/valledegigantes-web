## 01. GOAL

Turn a good-looking brochure into a B2B qualifying instrument with the melon as the
face of the brand. A wholesale or export buyer landing on any page, on a phone, must
within one screen be able to: see what is sold and from where, see that it is Primus
GFS certified, and reach a quote request or WhatsApp in one tap.

Keep the "Export Estate" palette and restraint. The typography gets lighter and more
classical; the imagery gets more honest. Nothing gets louder.

## 02. TECH STACK

- Static HTML, CSS and vanilla JS. No framework, no build step required to deploy.
- Hosted on GitHub Pages from `main`, custom domain `www.afergreens.com` (CNAME present).
- One shared stylesheet `assets/site.css` and one shared script `assets/site.js`,
  replacing the ~2,300 lines duplicated across the four product pages.
- No third-party runtime scripts. Icons are inline SVG (Lucide paths, ISC licence).
  Fonts self-hosted as subset woff2 in `assets/fonts/`.
- Image variants generated by `tools/images.py` (Pillow). Source PNGs and generated
  originals live outside the repo (see `IMAGES.md`).
- Forms post to FormSubmit using the random-string alias, captcha enabled.
- `404.html` at the root, branded, in Spanish, linking the four products and the form.
- `.gitignore` excludes `.claude/`, `.impeccable/`, `__pycache__/`.

## 03. DESIGN SYSTEM

Palette per `DESIGN.md`, with these corrections. Typography is new.

### Colors (unchanged tokens, corrected usage)

- Stone `#9B9585` restricted to light surfaces. Labels on dark surfaces use Agave Pale
  at 100% or Fog `#D5D0C6`.
- Add `scs-green-text: #567A1A`. SCS Green `#78A22F` for the badge fill only; all
  certification text, numbers and links use the dark variant.
- On Cantera Teal `#0D6558` sections, body text is Agave Soft `#E8F0E8`, eyebrows are
  Amber Light `#FBBD6E` or White.
- Delete the six off-palette colors on product pages, including `#E8830A`.
- Placeholder text `rgba(168,196,169,0.75)`. Footer text Agave Pale ≥75%.
- Focus ring: 2px solid Amber, 2px offset, via `:focus-visible`.

### Typography (replaces DESIGN.md section 3)

Display: **Cormorant Garamond**, Google Fonts, self-hosted subsets. Weights 300
(display, headline) and 400 (title, italic emphasis). Fallback `Georgia, serif`.
Body and UI: **Outfit** 300 / 500 / 600, unchanged.

| Role | Face | Size | Weight | Line height | Notes |
|---|---|---|---|---|---|
| Display (`h1`, once per page) | Cormorant | `clamp(3.4rem, 8.5vw, 8rem)` | 300 | 0.98 | `letter-spacing: -0.01em`, `max-width: 14ch`, `text-wrap: balance` |
| Headline (`h2`) | Cormorant | `clamp(2.4rem, 4.6vw, 4rem)` | 400 | 1.02 | sentence case |
| Title (`h3`, `h4`, card names) | Cormorant | `clamp(1.5rem, 2.2vw, 1.9rem)` | 500 | 1.1 | |
| Body | Outfit | `clamp(1rem, 1.5vw, 1.15rem)` | 300 | 1.7 | max 520px / 65ch |
| Label | Outfit | `0.72rem` | 600 | 1.2 | uppercase, `letter-spacing: 0.28em` |

Rules carried over: one italic amber `<em>` per `h1`/`h2`; Cormorant never in labels,
body or UI; Outfit never in headings. New rule: **Cormorant is never set bold** (600+);
its weight contrast comes from size, not stroke. Delete all Fraunces font files and
references. Delete the hard-coded 480px hero override; all sizes via `clamp()`.

### Named rules the current code breaks and this build must honor

- Rarity Rule: amber ≤10% of any surface. No amber section backgrounds.
- One Glow Rule: amber shadow on primary buttons only.
- SCS Quarantine Rule: SCS green only in certification contexts.
- No icon + heading + text card grids. Ficha técnica is a definition list.
- Motion on `transform` and `opacity` only. Header scroll effect uses a scale on the
  logo and a background-opacity fade, never height or padding.
- `scroll-margin-top: var(--header-h)` on every anchored section.

## 11. INTERACTIONS

- Header: single row, 64–72px on every viewport. Logo left (≤44px tall on mobile),
  `Cotizar` pill right, hamburger opening a full-screen sheet on ≤768px. Persistent
  `rgba(4,46,40,0.85)` background; `backdrop-filter` on scroll only.
- Scroll reveals via one shared `IntersectionObserver`, fire once, `opacity` +
  `transform` only. Content visible without JS.
- Parallax and custom cursor gated behind `@media (hover: hover) and (pointer: fine)`
  and `html.js-cursor`. rAF loop stops when the cursor is hidden. No `cursor: pointer`
  overrides.
- Grain overlay as a static tiled PNG at 3% opacity, not a blend-mode layer.
- Only two easings: `cubic-bezier(0.16,1,0.3,1)` and `cubic-bezier(0.4,0,0.2,1)`.

## 12. ACCESSIBILITY

WCAG 2.1 AA, verified.

- Skip link + `<main id="contenido">` on every page.
- Every text/background pair in 03 measured at ≥4.5:1 (≥3:1 for ≥24px). Cormorant at
  weight 300 is thin: below 32px use weight 400, and never set 300 on Agave Pale.
- `:focus-visible` on every interactive element.
- `prefers-reduced-motion` disables reveals, parallax, cursor, smooth scroll, and
  restores `cursor: auto`.
- No auto-moving content longer than 5s.
- Icon-only controls carry `aria-label`. External links announce the new window.
- Touch targets ≥44px. Nav order identical on all pages. `html lang="es-MX"`.
- Print stylesheet on product pages.
